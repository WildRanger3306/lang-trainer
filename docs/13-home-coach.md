# Home coach

Статус: **реализовано** (MVP).  
Связано: [11-adaptive-load.md](11-adaptive-load.md), [14-stats.md](14-stats.md).

## Зачем

На главной — короткий мотивирующий блок с именем, а не сухой список due/квоты.  
Сводка остаётся про цифры; главная — про импульс «как у меня дела».

## Решение

Шаблоны по сигналам (`advise_load` + due + активность 7д), **не** LLM.

| Сигнал | Tone | Смысл |
|--------|------|--------|
| только что сменился лимит | soft | сообщить о подстройке |
| никогда не занимались этим языком | start | «ещё не начинали» |
| пауза ≥ 3 календарных дня | welcome | «давно не виделись» |
| &lt; 20 отзывов за 7д (но были недавно) | neutral | факты due/новые |
| advice lower | soft | плотная неделя, добить due |
| advice raise | boost | можно прибавить |
| keep, due ≤ 15 | calm | спокойный день |
| keep, due &gt; 15 | push | due поднажало |

Пауза считается по последнему train-ответу / `last_review` / `introduced_on` **этого языка**, не по «0 ответов за неделю».

Имя: `User.label`. Цифры очереди компактно под текстом: `due · новых · без прогресса`.

Код: `app/coach.py`, рендер в `templates/filter.html`.
