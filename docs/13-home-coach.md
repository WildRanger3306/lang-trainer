# Home coach — proposal

Статус: **proposal** (не реализовано).  
Связано: [11-adaptive-load.md](11-adaptive-load.md), [12-fsrs.md](12-fsrs.md), перестройка сводки.

## Зачем

На главной сейчас сухой баннер очереди:

> Сейчас для французского: 0 due, новых осталось сегодня 20 …

Нужен короткий **мотивирующий** блок с именем (`display_name`), который отвечает «как у меня дела сегодня», а не только «что в очереди».

Сводка остаётся про цифры и autoload. Главная — про импульс.

## Решение (концепт)

Отдельная фича **home coach**: шаблоны по статусу из уже существующих сигналов (`advise_load` + due + активность), **не** свободный LLM-текст.

| Сигнал | Тон | Пример |
|--------|-----|--------|
| keep + due умеренный | поддержка | «Серафима, сегодня спокойный день: 12 повторов и ещё 8 новых.» |
| lower / again высокий | мягко | «Серафима, неделька была плотная — ты молодец. Сегодня лучше добить due.» |
| raise | буст | «Серафима, повторы стабильные — можно чуть прибавить.» |
| давно не было | без упрёка | «Серафима, давно не виделись. Начни с due.» |
| мало данных | нейтрально | «Серафима, сегодня: N повторов и до M новых.» |

Имя — `User.label` (`Серафима` / `Павел`). Род: нейтральные формулировки или карта по логину.

## Границы

- 1–2 фразы, всегда правда (due / новые / смена лимита).
- Не морализировать; не дублировать сводку (без again% и графиков).
- Цифры очереди рядом компактно: `due 12 · новых 0/20`.

## Код (когда делать)

- `app/coach.py` → `coach_message(user, language, load, advice) → {tone, text}`.
- Главная (`filter.html`) рендерит баннер; сводку не трогает.
- Переиспользовать те же статусы, что и autoload.
