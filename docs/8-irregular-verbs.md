# Неправильные глаголы (черновик)

Статус: **думать**, решения в [4-decisions.md](4-decisions.md) ещё нет. Зафиксировано 2026-09-12.

## Идея

Инфинитив остаётся обычным `entry` (как сейчас). Парадигма хранится **рядом**, не отдельными карточками.

### Почему так

- Уникальность `(язык, form, POS)` и прогресс Anki уже завязаны на **одну** единицу (`go` = verb).
- `went` / `gone` как отдельные `entries` дадут лишние карточки и дубли с вордлистами.
- Тема `irregular` только помечает «неправильный», но **не хранит формы**.

## Хранение (EN, Starlight)

Таблица `verb_paradigms` (1:1 к `entries`, где `part_of_speech = verb`):

| Поле | Пример |
|---|---|
| `entry_id` | → `go` |
| `language` | `en` (или брать из entry) |
| `past` | `went` |
| `past_participle` | `gone` |
| `present_participle` | `going` (опционально) |
| `note` | `be` / `have` / дефективы — текстом |

В JSON сырья — блок рядом с entry или отдельный файл `docs/words/irregular/en.json`:

```json
{ "form": "go", "past": "went", "pastParticiple": "gone" }
```

Линк при загрузке: `language=en` + `form` + `partOfSpeech=verb`.

## Карточки

- Обычный train: по-прежнему **go ↔ перевод**.
- На обороте (или подсказке): `go — went — gone`.
- Отдельный режим «формы» — позже, если понадобится; прогресс лучше не плодить на каждую форму.

## FR

Туда же не тащить полную спрягалку. Для французского либо:

- только флаг + ссылка на тип (`être`, `avoir`, 3e groupe),
- либо отдельная схема позже (présent / passé composé), когда появится режим.

## Не делать

- три `entries` на один глагол;
- пихать `went,gone` в `translations` или в `form`;
- ломать уникальность ради форм.
