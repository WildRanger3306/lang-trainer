# Oxford 3000 — сырой банк, не загружен полностью

Список 3000 самых важных английских слов по CEFR (A1–B2), официальный PDF Oxford University Press:
[oxford-3000-by-cefr-level.pdf](oxford-3000-by-cefr-level.pdf) (скачан с oxfordlearnersdictionaries.com — первоисточник, не сторонняя копия).

**Лицензия не проверялась.** OUP публикует этот PDF в открытом доступе для учителей/учеников, но формального разрешения на использование именно в этом проекте не искали. Файл лежит здесь для внутренней работы, не для публикации.

## Файлы

- [oxford3000.json](oxford3000.json) — весь список, 3297 уникальных пар (слово, часть речи): `form`, `pos` (значение enum `part_of_speech` проекта), `pos_code` (как в PDF, например `"n., v."`), `level` (минимальный CEFR-уровень), `levels` (все уровни, если слово встречается в нескольких — см. ниже), `gloss` (уточнение смысла из PDF в скобках, например `"(from the sun/a lamp)"`, если было).
- [todo_no_translation.json](todo_no_translation.json) — **1950 слов без русского перевода** (68% этого файла), т.е. то, что осталось сделать.

## Что уже сделано

1 347 слов (из 3297; попадают в 1281 при пересчёте только по Starlight 5–7, остальные — через Loiseau Blue/FR Trainer/оценку) совпали по (форма, часть речи) со словами, уже загруженными в базу из других учебников — их перевод переиспользован без изменений, без нового перевода. Эта часть загружена учебником **«Oxford 3000»** только в **тестовую** базу (`scripts/test_db.py`), в боевую — нет. Заодно у совпавших слов, где `level` был пустым, подтянулся настоящий CEFR-уровень из этого списка (побочный эффект `COALESCE` в `load_entries.py`, ничего не перезаписывает).

## Что не сделано

**1950 слов без перевода** — у Oxford 3000 нет русских переводов, только слово + часть речи + уровень, и без скана (это не учебник) перевод неоткуда взять, кроме как переводить самим. Переводить такой объём вручную с той же проверкой, что для страниц Starlight, — отдельная задача. Раскладка по уровням: A1 496, A2 449, B1 514, B2 557 (см. `todo_no_translation.json`).

## Заметки для следующего раза

- Некоторые слова встречаются на **двух уровнях** с разными смыслами одной части речи (например `bank n.` — A1 «деньги» и B1 «река»; `rest n.` — оба смысла на A2). У них `levels` содержит оба уровня, а `level` — младший; схема БД (`entries.level`) хранит только один уровень на пару (слово, часть речи), второй смысл теряется при загрузке — это ограничение модели данных, не будущей загрузки.
- Слова вида `second¹`/`close¹`/`close²`/`lie²` — омографы с разными значениями (в PDF помечены надстрочной цифрой); цифра из формы уже убрана в `form`, разные значения одной формы+части речи в модели данных не различаются (см. пункт выше).
- Парсинг PDF (4 колонки, разрывы строк, надстрочные цифры) был не совсем тривиальным — свежий разбор при необходимости можно повторить, PDF никуда не делся.
