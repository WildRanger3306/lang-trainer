# Как пользоваться тренажёром

Краткий гайд для ученика. В приложении тот же текст: экран **[/about](/about)** («О приложении»). Технические детали: [12-fsrs.md](12-fsrs.md), [11-adaptive-load.md](11-adaptive-load.md), [14-stats.md](14-stats.md).

## Что это

Веб-тренажёр словаря: **английский / французский ↔ русский**.  
Словарь общий, **прогресс личный** (логин). Каждый день: сначала повторы, потом немного новых слов.

### Банки данных (учебники)

В фильтре можно сузить пул по учебнику. Число — **уникальные лексемы** в БД (язык + форма + часть речи), привязанные к этому учебнику. Одна лексема может быть в нескольких классах, поэтому сумма по учебникам больше, чем «весь язык».

**Английский (Starlight)**

| Учебник | Лексем |
|---------|-------:|
| Starlight 5 | 1467 |
| Starlight 6 | 1302 |
| Starlight 7 | 1885 |
| *весь EN (уник.)* | *~4116* |

**Французский (Loiseau Blue)**

| Учебник | Лексем |
|---------|-------:|
| Loiseau Blue 5 | 608 |
| Loiseau Blue 6 | 557 |
| *весь FR без служебных наборов (уник.)* | *~1084* |

В тренировке каждая лексема даёт **две** карточки (язык→RU и RU→язык), если оба направления в очереди.

## Алгоритм (простыми словами)

**Интервальное повторение** опирается на исследования **Германа Эббингауза** (XIX в.): без повторений память о новом материале быстро падает («кривая забывания»), а вовремя повторённое удерживается дольше. Идея тренажёра — показывать карточку **перед тем, как она почти забылась**, а не каждый день подряд и не раз в год.

Современный расчёт сроков в приложении делает **FSRS** (на базе той же логики spaced repetition, что и в Anki):

1. **Карточка** — одна сторона (слово или перевод), после переворота — ответ.
2. Ты оцениваешь, **насколько уверенно вспомнил** (4 кнопки).
3. FSRS считает, когда показать карточку снова (`due`). Чем увереннее ответ — тем позже повтор; чем тяжелее — тем раньше.
4. В день система даёт все **просроченные** (`due`) + ограниченное число **новых** (лимит: EN обычно 10, FR 20; может менять **autoload**).
5. **Again** ещё и возвращает карточку **в конец сегодняшней сессии**.

Отдельно есть **оценка знаний**: быстрый триаж «уже знаю / сомневаюсь / не знаю» — не жжёт дневной лимит новых; дальше эти карточки идут в обычную тренировку по FSRS.

## Основные термины

| Термин | Значение |
|--------|----------|
| **Due** | Карточки, которые пора повторить сегодня (и просроченные). |
| **Новые** | Ещё ни разу не были в твоём прогрессе (в этом направлении). |
| **Лимит новых** | Сколько новых можно взять за день (на язык). |
| **Без прогресса** | Сколько таких «ещё не тронутых» карточек в текущем фильтре. |
| **Фильтр** | Учебник / темы — сужает пул; «весь язык» = без ограничений. |
| **Направление** | Язык→RU или RU→язык. У EN чаще сначала RU→EN, у FR — FR→RU. |
| **FSRS** | Алгоритм интервалов по твоим Again/Hard/Good/Easy. |
| **Autoload** | Автоподстройка лимита новых (±5), если 3 дня подряд один и тот же сигнал «снизить» или «усилить». |
| **Корпус** | Все карточки выбранного языка и как они распределены (новые / частый повтор / редкий). |
| **Горизонт** | Грубая оценка, сколько займёт первый проход оставшихся новых. |

## Как пользоваться

### Вход и главная

1. Войти (логин / пароль).
2. Выбрать язык (EN / FR), при необходимости — **Фильтры**.
3. Прочитать короткий текст coach и строку `due · новых · без прогресса`.
4. **Тренировка** — основная сессия. **Оценка знаний** — разобрать уже знакомые слова пачкой.

### Тренировка

1. Смотришь лицо карточки → вспоминаешь.
2. Переворот — сверка.
3. Жмёшь одну из четырёх кнопок.
4. В конце — итог сессии.

### Кнопки Again / Hard / Good / Easy

Оценивай **этот момент**, не «насколько слово важное».

| Кнопка | Когда | Эффект (идея) |
|--------|--------|----------------|
| **Again** | Не вспомнил, ошибся, угадал | Скоро снова + ещё раз в этой сессии |
| **Hard** | Вспомнил с трудом, долго думал | Короткий интервал |
| **Good** | Нормально вспомнил | Обычный следующий срок |
| **Easy** | Мгновенно и очень уверенно | Позже увидишь снова |

**В первый раз** (новая карточка): чаще **Good**, реже **Hard**, **Again** если не зацепилось. **Easy** почти не ставь — только если слово и так давно знаешь.

**На повторах:** честно. Много Easy «на авось» размазывает интервалы; много Again без нужды — наоборот, забивает очередь.

### Оценка знаний

- **Знаю** → повтор примерно через неделю, лимит новых не тратится.  
- **Сомневаюсь / Не знаю** → скоро в тренировке.  
Дальше для этих карточек — уже Again/Hard/Good/Easy.

## Как читать прогресс (Сводка)

Открой **Сводка**, переключи язык при необходимости.

### Сегодня
- **due** — сколько надо повторить сейчас.  
- **новых a / b** — сколько уже взял сегодня из лимита.  
- **лимит** и **серия** (например `lower 2/3`) — что делает autoload.

### Autoload
Полоска lower / keep / raise за месяц. Лимит сам ±5 после **3 дней** одного сигнала — руками крутить не нужно.

### Качество (FSRS)
Доли **Again / Hard / Good / Easy** за неделю.  
Много Again/Hard + большой due → система склонна **снизить** новые.  
Стабильно Good/Easy и маленький due → может **поднять** лимит.

### Нагрузка
График ответов и новых за 30 дней — видна привычка и объём.

### Корпус
Сколько ещё новых и сколько уже «в системе» (короткий / средний / длинный повтор).

### Горизонт
Ориентир «когда примерно пройду оставшиеся новые» при текущем лимите — не обещание, а прикидка.

## Мини-чеклист на день

1. Сначала добей **due**.  
2. Потом новые в пределах лимита.  
3. На кнопках будь честен; на новых по умолчанию **Good**.  
4. Раз в несколько дней глянь **Сводку**: due не раздувается? Again% не зашкаливает?
