# Стратегия тренировок

План занятий в тренажёре. Поведение продукта — [2-requirements.md](2-requirements.md). Лимиты и режимы — как в коде (`app/scheduler.py`).

Прогресс **личный** (логин); словарь учебников **общий**. Аккаунты не делить.

**Класс:** 7-й (уч. год **2026–2027**, затем 8-й **2027–2028**).  
Школа: **углублённый английский** (**Starlight 7**) и **Loiseau Blue 6** (FR).  
Оба курса тянутся **~2 года**; слова бьём на модули / юниты по **~1,5 месяца**.

**Переход:** до 7 класса — обычная школа + курсы (**оценка ~A2**). Starlight — линия углублёнки; у одноклассников за плечами обычно SL5→SL6. Дыра не в «всём A2», а в **лексике/фразах Starlight**, которой в обычной программе часто нет.

| | EN | FR |
|--|----|----|
| Опыт | ~A2 (курсы); линия Starlight — **с пробелами** | **с нуля** |
| Оценка знаний | **да** — SL7, затем мост SL6→SL5 | **нет** — почти всё новое |
| Фокус | **SL7** (школа) + мост **SL6**, позже **SL5** | **LB6** (+ опционально мост LB5) |
| Новых/день | **10** | **20** |
| Приоритет направления | RU→EN | FR→RU |
| Слов в БД (ориентир) | SL7 ≈1885; вне SL7 ещё ≈2231 из SL5∪SL6 | LB5 ≈608; LB6 ≈557 (U1–6 ≈331; U7–12 ≈236) |

### Какой CEFR ждать в 7 классе углублёнки

Ориентиры (не жёсткий норматив одной школы):

| Контекст | Уровень |
|----------|---------|
| Обычная школа к 9 классу | часто ~**A2** |
| Углублёнка: цель к концу основной школы (9 кл.) | часто ~**B1** |
| **7 класс углублёнки (сейчас)** | материалы и ожидания примерно **A2+ … начало B1** |
| Курсы «A2» при входе | нормальный старт; отставание скорее в **объёме тематической лексики Starlight**, не в том, что «не A2» |

Starlight 7 как раз сидит в зоне A2+/B1. Догнать линию = не выучить все 2200+ «лишних» слов SL5/SL6 сразу, а закрыть мост (ниже), параллельно идя по школе.

Оценка (только EN): пачки до **40**, дневную квоту новых не жжёт.

| Вердикт оценки | В Anki |
|----------------|--------|
| Знаю | due через 7 дней |
| Сомневаюсь / Не знаю | due завтра |

## Принцип по языкам

### Английский — сначала оценка

1. **Оценка** знакомого в текущем фильтре (учебник SL7 / темы модуля) — не жечь 10 новых на то, что уже знаешь.
2. Потом ежедневная **тренировка** = все due + порция новых.
3. В оценке «Знаю» только при уверенности; иначе «Сомневаюсь».

Оценка не обязательна как вход: без триажа слова всё равно попадут в тренировку как новые — просто дольше.

### Французский — сразу тренировка

1. Оценка **не нужна**: корпус с нуля, триаж почти ничего не сэкономит.
2. Ежедневно: **due + новые** (до 20) в текущем фильтре тем.
3. Новый юнит ≈ каждые 1,5 мес — просто добавляем тему в фильтр и вводим слова квотой.

### Общее

- Один язык в фокусе захода (или утро/вечер), иначе due раздуется на обоих.
- Будни: чередовать по школе (SL7 / текущий FR-юнит).
- Due держать комфортными ~20–40 ответов за заход; не гонять оба «полным газом», пока due не устаканится.

## Фильтры

**EN:** язык `en` + учебник **Starlight 7** и/или тема модуля (`sl7_m1` для Module 1; дальше `sl7_m2` …). Канон тем Vocabulary — [words/topics/starlight_7_canon.md](words/topics/starlight_7_canon.md). Starter в фильтр **не** берём (revision; почти нет в WL).

**FR:** язык `fr` + **темы** (`lb5_all` при мосте, `lb6_u01` … `lb6_u12`). Учебник в UI можно не трогать. Юниты LB6 **накапливаются**: к окну добавляем следующий `lb6_uNN`, старые не выключаем (due остаётся).

## Английский · Starlight 7 (2026–2028)

Канон модулей / Vocabulary: [starlight_7_canon.md](words/topics/starlight_7_canon.md).

Ориентир: **~1,5 мес на модуль**, старт ≈ **сентябрь**. Starter пропускаем в тренажёре; с Module 1. Хвост и повторы — во 2-й год при необходимости.

| Модуль | Окно (ориентир) | Фокус в тренажёре | ~слов в фильтре |
|--------|-----------------|-------------------|----------------:|
| **Starter** | — | **не в фильтре** | — |
| **Module 1** Work & Play | сен – сер. окт | тема **`sl7_m1`** (~171 в WL; +additional позже) | ≈171 |
| **Module 2** Culture & Stories | сер. окт – кон. ноя | `sl7_m2` (когда разметим) | |
| **Module 3** Mother Nature | дек – сер. янв | | |
| **Module 4** Healthy mind… | сер. янв – кон. фев | | |
| **Module 5** Life experiences | мар – сер. апр | | |
| **Module 6** Crime & community | сер. апр – кон. мая | закрыть год; лето — due | |

При **10 новых/день** кусок M1 (~171) — это порядка **2–3 недель** чистого ввода, если мало «Знаю» в оценке; с оценкой часто быстрее. Остаток окна 1,5 мес — due + школа, не «выжечь модуль за 4 дня».

**Ритуал нового модуля (~каждые 1,5 мес):**

1. Фильтр: тема текущего модуля (`sl7_m1` …), учебник SL7 по желанию.
2. **Оценка** 1–2×40 по новому куску.
3. Дальше: due всего открытого + новые с приоритетом текущего модуля.

### Мост SL6 → SL5 (догнать углублёнку)

В БД **нет CEFR** на словах — автоматически отделить «обычная школа» от «углублёнка» нельзя. Практичный прокси:

| Что | Зачем |
|-----|--------|
| Пересечения SL5/SL6 ∩ SL7 | Уже внутри SL7 — отдельный фильтр не нужен |
| Только SL6 ∉ SL7 (~950) | Ближе к текущему классу; типичный «хвост» линии углублёнки |
| Только SL5 ∉ SL6/SL7 (~1110) | Более ранний пласт; позже |
| SL5 ∩ SL6 ∉ SL7 (~171) | Общий «не доехавший» до SL7 запас — можно зацепить вместе с SL6 |

Что в обычной школе / чистом A2 часто **слабее**, а в Starlight гуще: **phrases / phr v**, тематические гнёзда модулей, word formation. Имеет смысл в оценке и вводе моста **не скиповать фразы**.

**Как подключать (темы в UI, не весь учебник):**

| Тема | Состав | ~слов |
|------|--------|------:|
| `bridge_sl6` | есть в **SL6**, нет в **SL7** (в т.ч. пересечение SL5∩SL6∉SL7) | ≈1121 |
| `bridge_sl5` | есть **только** в **SL5** (нет в SL6 и SL7) | ≈1110 |

**Когда включать `bridge_sl6` (при текущем M1):**

Не ждать конца 1,5 мес модуля. M1 маленький относительно моста (~171 vs ~1121) — школа сначала, мост **параллельно вечерами**, когда база M1 уже не горит.

| Фаза | Когда (ориентир) | Что делать |
|------|------------------|------------|
| **Только `sl7_m1`** | первые **1–2 недели** M1 | оценка пачками → due + новые; мост **выкл** |
| **Можно + `bridge_sl6`** | M1 в основном протриажен **и** due EN комфортный (~20–40 за заход), again не давит | **1–2 вечера в неделю** (или часть квоты новых): фильтр `bridge_sl6` → оценка → due + немного новых. Дни школы — снова `sl7_m1` |
| **Не рано** | due M1/SL7 раздут, много Again, неделя пропусков | мост отложить; сначала только due |
| **Не одновременно** | — | не держать `sl7_m1` + `bridge_sl6` + `bridge_sl5` в одном фильтре «на всякий случай» |

Практичный якорь по календарю: **конец сентября – начало октября 2026** (середина/вторая половина окна M1), если сводка спокойная. К **сер. октября** (старт M2) мост уже может идти фоном; `bridge_sl5` — только когда SL6 в основном закрыт оценкой.

Критерий «мост достаточно»: в пачках оценки по bridge почти нет «Не знаю» по базовым словам; due моста укладывается в вечер без отмены SL7.

## Фазы (уточнение)

| | EN | FR |
|--|----|----|
| Старт куска | **оценка** → due + новые | сразу **due + новые** |
| Режим | сводка → due → квота → при большом «без прогресса» ещё пачка оценки | сводка → due → квота |
| «Протриажен» | в фильтре почти нет карточек без прогресса | не применяется |

## Как читать сводку

| Сигнал | Действие |
|--------|----------|
| again по повторам высокий / due давит | меньше новых, больше дней только due |
| due маленький, «помню» стабильно | можно позже поднять лимит новых в коде |
| много «Знаю» в оценке EN, через неделю again | строже с «Знаю» |
| пропуск дня | сначала закрыть due, новые не добивать |
| новый модуль/юнит, due раздулся | временно новые 0–10 (EN) / 0–10 (FR), пока due не сядет |
