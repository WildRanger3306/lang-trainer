# Стратегия тренировок

План занятий в тренажёре. Поведение продукта — [2-requirements.md](2-requirements.md). Лимиты и режимы — как в коде (`app/scheduler.py`).

Прогресс **личный** (логин); словарь учебников **общий**. Аккаунты не делить.

**Класс сейчас:** 7-й (уч. год **2026–2027**).  
Школа: **Starlight 7** (EN) и **Loiseau Blue 6** (FR).  
FR-база «с нуля»: сначала **Loiseau Blue 5**, затем юниты LB6 по школьному календарю.

## Исходные цифры

| | EN | FR |
|--|----|----|
| Слова / карточки (2 направления) | ~3006 / ~6012 (весь корпус; фокус — Starlight 7) | LB5 ~622 / ~1244; LB6 ~567 / ~1134 (U1–6 ≈331 / ≈662; U7–12 ≈236 / ≈472) |
| Новых/день | **10** | **20** |
| Приоритет направления | RU→EN | FR→RU |
| Школьный учебник | **Starlight 7** | **Loiseau Blue 6** (2 части: U1–6 → U7–12) |
| Старт FR | — | **LB5** (мост), потом юниты LB6 |

Оценка знаний: пачки до **40**, дневную квоту новых не жжёт.

| Вердикт оценки | В Anki |
|----------------|--------|
| Знаю | due через 7 дней |
| Сомневаюсь / Не знаю | due завтра |

## Принцип

1. Сначала **оценка** знакомого в текущем фильтре — не жечь 10/20 новых на то, что уже знаешь.
2. Потом ежедневная **тренировка** = все due + порция новых.
3. Один язык в фокусе дня (или жёсткое окно по времени), иначе due раздуется на обоих.
4. В оценке «Знаю» только при уверенности; иначе «Сомневаюсь».

Оценка — не обязательный вход в Anki: без триажа слова всё равно могут попасть в тренировку как новые.

**Фильтр FR:** язык `fr` + **темы** (`lb5_all`, `lb6_u01` … `lb6_u12`). Учебник в UI можно не трогать — метки уже на словах. Юниты LB6 **накапливаются**: к новому окну добавляем следующий `lb6_uNN`, старые не выключаем (due по ним остаётся). Мост: тема **`lb5_all`**.

### Мост: Loiseau Blue 5 (сейчас)

Французский «с нуля» → сначала **LB5**, не открывать весь LB6 сразу.

1. Фильтр: язык FR, тема **`lb5_all`** (учебник не обязателен).
2. **Оценка** 1–2 пачки/день, пока много «без прогресса».
3. Параллельно **тренировка**: due + квота новых (до 20/день).
4. Критерий «можно подключать LB6 U1»: LB5 в основном протриажен **или** школа уже ушла в U1, а due по LB5 ещё терпимый — тогда в темах держать `lb5_all` + `lb6_u01` (LB5 на due, новые из U1).

### Ритуал при открытии нового юнита (каждые ~1,5 мес)

1. В фильтре: темы **все открытые** (`lb5_all` пока нужен + `lb6_u01`…). Учебник можно не отмечать.
2. **Оценка** 1–2×40 только по **новому** юниту (отметить только `lb6_uNN`).
3. Дальше ежедневно: due (весь открытый корпус по темам) + новые с приоритетом текущего юнита.
4. LB5: тема `lb5_all` — due закрывать; новые из LB5 не добивать, пока идёт текущий юнит LB6 (можно временно снять `lb5_all` с фильтра новых / оставить только для due отдельной сессией).

## Английский (кратко)

- Фокус: **Starlight 7** — оценка → due + 10 новых/день.
- Starlight 6 — запасной корпус, не приоритет, пока SL7 не устаканится.
- Канон тем Vocabulary: [words/topics/starlight_7_canon.md](words/topics/starlight_7_canon.md).

## Фаза 0 → фаза 1 (общий ритм)

**Фаза 0 (триаж фильтра):** оценка знакомого, новые по минимуму.  
**Фаза 1 (режим):** сводка → due → квота новых → 0–1 пачка оценки, если ещё много «без прогресса» в **текущем** юните/учебнике.

**Критерий «протриажен»:** в текущем фильтре почти нет карточек без прогресса (или остались заведомо трудные).

**Сплит EN / FR:**

- будни: чередовать по школе (SL7 / текущий FR-фильтр);
- либо утро / вечер; due держать комфортными ~20–40 ответов за заход;
- не запускать оба «полным газом» в один день, пока due не устаканится.

## Как читать сводку

| Сигнал | Действие |
|--------|----------|
| again по повторам высокий / due давит | меньше новых, больше дней только due |
| due маленький, «помню» стабильно | можно позже поднять лимит новых в коде |
| много «Знаю» в оценке, через неделю again | строже с «Знаю» |
| пропуск дня | сначала закрыть due, новые не добивать |
| новый юнит LB6, due раздулся | временно новые 0–10, пока due не сядет |
