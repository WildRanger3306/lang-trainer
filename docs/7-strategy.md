# Стратегия тренировок

План занятий в тренажёре. Поведение продукта — [2-requirements.md](2-requirements.md). Лимиты и режимы — как в коде (`app/scheduler.py`).

Прогресс **личный** (логин); словарь учебников **общий**. Аккаунты не делить.

**Класс сейчас:** 7-й. Школьные учебники — **Starlight 7** (EN) и **Loiseau 7** (FR).

## Исходные цифры

| | EN | FR |
|--|----|----|
| Слова / карточки (2 направления) | ~3006 / ~6012 (весь корпус; фокус — Starlight 7) | ~1084 / ~2168 (пока Blue 5–6; после загрузки Loiseau 7 — пересчитать) |
| Новых/день | **10** | **20** |
| Приоритет направления | RU→EN | FR→RU |
| Учебник 7 класса | **Starlight 7** (в базе) | **Loiseau 7** (ещё нет; ожидается **15 сентября**) |

Оценка знаний: пачки до **40**, дневную квоту новых не жжёт.

| Вердикт оценки | В Anki |
|----------------|--------|
| Знаю | due через 7 дней |
| Сомневаюсь / Не знаю | due завтра |

## Принцип

1. Сначала **оценка** знакомого из учебника **текущего класса** — не жечь 10/20 новых на то, что уже знаешь.
2. Потом ежедневная **тренировка** = все due + порция новых.
3. Один язык в фокусе дня (или жёсткое окно по времени), иначе due раздуется на обоих.
4. В оценке «Знаю» только при уверенности; иначе «Сомневаюсь».

Оценка — не обязательный вход в Anki: без триажа слова всё равно могут попасть в тренировку как новые.

Фильтр на сессии: **язык + учебник 7 класса** (не весь корпус и не старые тома сразу).

## Фаза 0 — старт (сейчас → ~2 недели)

**Цель:** вынести уже известное из «новых» по учебникам 7 класса.

### Сейчас (до 15 сентября)

- **EN:** фильтр Starlight 7 → оценка **1–2 пачки/день** (40–80).
- **FR:** Loiseau 7 ещё не в базе — французский не триажить «вслепую» по Blue 5–6 как по школьному. Пока: только due по FR, если уже есть прогресс; иначе фокус на EN.
- После пачки EN — короткая **тренировка** due (если появились «не знаю / сомневаюсь»).
- Новые в тренировке EN в эти дни — по минимуму или 0, пока идёт триаж Starlight 7.

### С 15 сентября (после загрузки Loiseau 7)

- Залить Loiseau 7 → фильтр **Loiseau 7**.
- Фаза 0 для FR: **1–2 пачки оценки/день**, пока учебник не протриажен.
- EN: добить остаток Starlight 7 оценкой, если ещё много «без прогресса»; иначе перейти к фазе 1.

**Критерий «учебник протриажен»:** в фильтре по учебнику почти нет карточек без прогресса (или остались только заведомо трудные).

Старые тома (Starlight 6, Loiseau Blue 5–6) — запасной корпус, не школьный приоритет 7 класса; к ним позже, когда текущие учебники закрыты.

## Фаза 1 — режим (когда текущий учебник в основном протриажен)

**Ежедневно (15–40 мин):**

1. Сводка → due и совет по нагрузке.
2. **Тренировка** до конца due (или «Завершить», если время вышло — due останется).
3. Добить квоту новых, если due уже не давит.
4. 0–1 пачка **оценки**, если ещё много «без прогресса» в текущем учебнике 7 класса.

**Нагрузка (ориентир):**

- только EN ≈ 10 новых/день → первый проход словаря порядка ~10 мес (оба направления дольше);
- только FR ≈ 20/день → быстрее по объёму;
- оба языка каждый день — due растёт быстрее; смотреть график активности и again rate.

**Сплит двух языков (7 класс):**

- будни: чередовать Starlight 7 / Loiseau 7 по школьной нагрузке;
- либо утро / вечер по языкам, держа due в комфортных ~20–40 ответов за раз;
- после появления Loiseau 7 не запускать оба «полным газом» в один день, пока due не устаканится.

## Как читать сводку

| Сигнал | Действие |
|--------|----------|
| again по повторам высокий / due давит | меньше новых, больше дней только due |
| due маленький, «помню» стабильно | можно позже поднять лимит новых в коде |
| много «Знаю» в оценке, через неделю again | строже с «Знаю» |
| пропуск дня | сначала закрыть due, новые не добивать |

## План на ближайшие 2 недели

Ориентир от **11 сентября** (сегодня) / загрузка Loiseau 7 — **15 сентября**.

| Дни | Действие |
|-----|----------|
| 11–14 | EN: оценка Starlight 7, 1–2×40; тренировка due. FR: без триажа школьного учебника (его ещё нет) |
| 15–17 | Загрузка Loiseau 7. FR: старт оценки Loiseau 7, 1–2×40. EN: due + добивка остатка SL7 оценкой |
| 18–24 | Оба: due + аккуратно квота новых; 0–1 пачка оценки по тому учебнику, где ещё много «без прогресса» |

Уточнять под ученика: кто тренируется, какой язык главнее в школе на этой неделе, сколько минут в день.
