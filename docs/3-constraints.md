# Ограничения

Жёсткие рамки MVP. Если меняется поведение продукта — править [2-requirements.md](2-requirements.md). Если «в этой итерации делаем меньше» — [6-iterations.md](6-iterations.md).

## Кто и где

- Один пользователь. Аккаунтов, ролей и общего словаря нет.
- Только веб в браузере. Мобильного приложения нет.
- Вёрстка адаптивная: один интерфейс на телефоне и на компьютере.
- Родной язык — русский. Изучаемые — английский и французский. Других языковых пар нет.

## Что не строим в MVP

- экран добавления и редактирования слов;
- просмотр словаря;
- история прошлых сессий как отдельный архив (даты/итоги сессий); сводка по ответам — в требованиях;
- импорт JSON (поля единицы — [5-data-model.md](5-data-model.md));
- Yandex API (переводы кладёт агент вместе со словами);
- аккаунты;
- мобильное приложение;
- набор ответа с клавиатуры и выбор из вариантов;
- автосмена лимита новых по статусу сводки;
- FSRS, Hard/Easy, тепловые карты, геймификация.

## Загрузка словаря

Слова в БД кладёт агент. Интерфейса загрузки нет.

Источник материала — учебники, записи и сканы в `docs/words/raw/`.

## Повтор

Упрощённый Anki / SM-2 (Again / Good), см. требования. Без Hard/Easy, без FSRS, без минутных шагов learning.

## Отложено (следующая волна, не MVP)

Импорт JSON, Yandex API, просмотр словаря, история сессий как архив, CRUD слов, аккаунты, мобильное приложение, набор и выбор ответа, автоподстройка лимита новых, разбивка сводки по темам.
