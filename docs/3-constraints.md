# Ограничения

Жёсткие рамки. Если меняется поведение продукта — править [2-requirements.md](2-requirements.md). Если «в этой итерации делаем меньше» — [6-iterations.md](6-iterations.md).

## Кто и где

- Несколько пользователей на одном инстансе (логин / пароль). Ролей в UI нет.
- Словарь учебников **общий**; прогресс **личный**.
- Только веб в браузере. Мобильного приложения нет.
- Вёрстка адаптивная: один интерфейс на телефоне и на компьютере.
- Родной язык — русский. Изучаемые — английский и французский. Других языковых пар нет.
- Один деплой (дом / VPS), не публичный SaaS.

## Что не строим сейчас

- публичная саморегистрация, OAuth, email, 2FA;
- роли admin/teacher, экран «все ученики», шаринг прогресса;
- смена пароля в UI (только скрипт);
- per-user словарь и per-user лимиты новых в UI (лимиты EN/FR общие константы);
- экран добавления и редактирования слов;
- просмотр словаря;
- история прошлых сессий как отдельный архив (даты/итоги сессий); сводка по ответам — в требованиях;
- импорт JSON (поля единицы — [5-data-model.md](5-data-model.md));
- Yandex API (переводы кладёт агент вместе со словами);
- мобильное приложение;
- набор ответа с клавиатуры и выбор из вариантов;
- автосмена лимита новых по статусу сводки (планируется: [4-decisions.md](4-decisions.md) §011; ручной UI и lock — позже);
- FSRS, Hard/Easy, тепловые карты, геймификация.

## Загрузка словаря

Слова в БД кладёт агент. Интерфейса загрузки нет.

Источник материала — учебники, записи и сканы в `docs/words/raw/`.

## Повтор

Упрощённый Anki / SM-2 (Again / Good), см. требования. Без Hard/Easy, без FSRS, без минутных шагов learning.

## Отложено (следующая волна)

Импорт JSON, Yandex API, просмотр словаря, история сессий как архив, CRUD слов, роли/админка учеников, смена пароля в UI, мобильное приложение, набор и выбор ответа, автоподстройка лимита новых, разбивка сводки по темам, публичная регистрация.
