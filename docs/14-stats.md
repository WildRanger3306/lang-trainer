# Сводка после FSRS и autoload

Статус: **реализовано** (перестройка UI + метрик).  
См. [4-decisions.md](4-decisions.md) §013. Proposal главной: [13-home-coach.md](13-home-coach.md).

## Зачем

Сводка была про «решить, менять ли лимит» и Anki-«помню/again».  
После autoload лимит двигается сам; после FSRS есть 4 оценки. Сводка отвечает на три вопроса:

1. Успеваю ли сегодня? (due vs привычный объём)
2. Не перегружаю ли себя? (Again/Hard, что делает авто)
3. Куда движется корпус? (сегменты + горизонт)

## Структура экрана

| Блок | Содержание |
|------|------------|
| **Сегодня** | due, новых/лимит, ответов вчера; статус авто (лимит, база, серия N/3) |
| **Autoload** | серия lower/raise, последняя смена, мини-ряд статусов совета за 30 дн |
| **Качество (FSRS)** | распределение Again/Hard/Good/Easy за 7 дн; линия Again% за 30 дн |
| **Нагрузка** | график ответов/новых (как было) |
| **Корпус** | stacked bar; подписи «повтор ≤6 / 7–20 / ≥21 дн» |
| **Горизонт** | ETA первого прохода (вторичный блок) |

Убрано с UI: «сброс на interval 1»; баннер «совет: меняй лимит вручную».

## Сигналы autoload

Без изменений алгоритма (`advise_load`). На UI: объяснить, что система **уже делает / вот-вот сделает**, не призывать крутить лимит руками.
