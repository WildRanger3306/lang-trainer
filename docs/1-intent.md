# Намерение

Личный веб-тренажёр словарного запаса: английский и французский ↔ русский.

Цель MVP — быстро запускать сессию по фильтру и оценивать себя переворотом карточки («помню / не помню»). Один пользователь, без аккаунтов. Словарь наполняет агент прямо в БД; экрана управления словами нет.

Следующий этап (не MVP): импорт (например JSON), Yandex API, просмотр словаря и история сессий.
